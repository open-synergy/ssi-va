============================================
Virtual Account + Operating Unit Integration
============================================

Adds a single Operating Unit (``operating_unit_id``) to the Virtual Account
Generator (``va_generator``) document and to the *Generate VA* wizard, so
Virtual Account generation batches can be scoped and restricted per
Operating Unit in addition to per company.


Work Instruction
================

* `Virtual Account Generator <docs/va_generator/index.html>`_


Installation
============

To install this module, you need to:

1.  Clone the branch 14.0 of the repository https://github.com/open-synergy/ssi-va
2.  Add the path to this repository in your configuration (addons-path)
3.  Update the module list (Must be on developer mode)
4.  Go to menu *Apps -> Apps -> Main Apps*
5.  Search For *Virtual Account + Operating Unit Integration*
6.  Install the module
